# Prog 1.3.0

세션을 탭으로 나눠 쓰고, 저장한 파일을 새 탭으로 여는 버전이다. 자세한 설명은 README의 세션 탭 절.

## 세션 탭

- 창 탭(네이티브 탭)으로 세션을 여러 개 둔다. 탭마다 필터·선택·정렬·사이드바 선택이 따로 있고, 라이브 탭끼리는 같은 캡처를 공유한다.
- **New Session** ⌘T, **Close** ⌘W, **Close All** ⌥⌘W(도구 창까지 Prog 창을 모두 닫음), 다음·이전 탭 ⇧⌘]·⇧⌘[.
- 사이드바 항목 우클릭 **Open as New Tab**.

## 파일 열기

- 파일은 새 파일 탭으로 열리고, 더 이상 라이브 세션을 덮어쓰지 않는다.
- **Open…** ⌘O, **Open Recent ▸ Clear Menu**, 끌어다 놓기, Finder 더블클릭, `open -a`로 연다. 앱이 문서 종류를 선언했다.
- **Save Session** ⌘S.
- HAR를 가져오면 클라이언트 이름이 복원되고 사이드바가 이름별로 묶는다.

## 원격 기기 이름

- 원격 기기 이름을 Bonjour 광고(AirPlay·Companion Link·Google Cast)에서 자동으로 가져온다. 직접 정한 이름이 항상 우선한다.
- 원격 기기가 처음 트래픽을 보내면 macOS **로컬 네트워크** 권한 창이 한 번 뜬다. 허용해야 이름을 찾는다.
