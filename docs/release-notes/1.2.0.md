# Prog 1.2.0

메인 화면을 Proxyman 배치·이름·단축키에 맞췄다. 자세한 설명은 README의 메인 화면·상세 패널·설정 절.

## 메인 화면

- **기록 버튼**: 누르면 할 일을 보인다(기록 중 ⏸, 멈춤 ▶). 목록은 최신 요청이 위(ID 내림차순).
- **툴바 캡슐**: `● Prog | Listening on <IP>:<포트>`. 새 버전이 있으면 오른쪽에 `New Update ⚠` 배지가 뜨고, 누르면 업데이트 창이 열린다.
- **필터 막대(⌘F)**: 툴바 검색칸 대신 규칙 여러 줄(키 16가지 × 매칭 12가지, AND/OR, 최대 10줄). 규칙은 다시 켜도 남는다.
- **사이드바**: Favorites ▸ Pinned, Remote devices, All ▸ All Requests·Apps·Domains, 도메인 아래 경로 트리. `+`로 도메인 고정, 우클릭 Pin·Enable SSL Proxying·Copy Domain.
- **하단 바**: Clear·Filter·Auto Select, 선택 행 수, 메모리·속도, 켜진 도구 배지(누르면 그 도구 창).
- 트래픽이 몰릴 때도 목록·필터 입력이 버벅이지 않게 했다.

## 상세 패널

- 메서드·상태·URL을 색으로 나눈 머리, Request·Response 탭 묶음.
- 내용이 있을 때만 보이는 탭: Form·Cookies·Auth·Set-Cookie·M3U8.
- Summary·Treeview·JSON 탭, 표 거르기 옵션(대소문자·정규식).
- 복호화되지 않은 CONNECT 행에서 그 도메인만 또는 그 앱의 모든 도메인을 바로 SSL Proxying에 넣는 버튼.

## 설정

- General·Appearance·Tools·SSL Proxying·Bypass·Advanced 여섯 탭.
- 새 설정: 실행 시 시스템 프록시 자동 적용, 자동 기록 시작, 글꼴 크기·탭 폭·줄무늬·공백 표시, Request Timeout, cURL `--proxy`, Export 뒤 Finder 열기, Stay On Top, 종료 확인, 시뮬레이터의 Apple 요청 숨김.
- 기본값 변경: 목록 줄무늬 켬, 긴 URL은 끝을 줄임, 본문 글꼴 13pt, Request Timeout 30초.

## 설치·업데이트

- 업데이트 주소를 새 서버로 옮겼다. 이 버전부터는 업데이트 창에 릴리스 노트가 보인다.
- 처음 설치는 DMG로: 열어서 Prog를 Applications 폴더로 끌어다 놓는다. 설정과 루트 인증서는 그대로 유지된다.
