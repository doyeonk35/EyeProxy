# Prog 1.4.0

SSL Proxying 호스트 목록을 파일로 주고받고, 호스트 묶음을 탭으로 여는 버전이다. 자세한 설명은 README.

## SSL Proxying 호스트 목록

- 호스트 목록을 텍스트 파일로 **가져오기·내보내기**한다. 한 줄에 패턴 하나, `#`은 주석이고 Proxyman SSL 목록 JSON도 읽는다.
- 가져오기는 기존 목록에 **덧붙이기만** 하고, 적용 전에 확인 창을 띄운다.
- `*`, `?`, `.`만으로 된 패턴이 있으면 모든 HTTPS를 복호화한다는 경고가 뜬다.
- 팀이 저장소 밖에 둔 호스트 목록 파일을 한 번에 가져와 공유할 수 있다.
- 사이드바 기기·앱 행 메뉴에 **Enable SSL Proxying for All Domains**가 생겼다.

## 호스트 묶음 탭

- **File ▸ New Domain or App** ⇧⌘K, **Favorites ▸ Groups**로 호스트 묶음을 만들고 탭으로 연다.
- 종료할 때 열려 있던 탭이 다음 실행에 되살아난다. 설정 **Restore Tabs at Launch**로 끌 수 있다.

## 기기 이름

- 기기를 MAC 주소로 알아본다. IP가 바뀌어도 직접 정한 이름이 따라간다. **로컬 네트워크** 권한이 필요할 수 있다.
- 이 Mac의 LAN IP가 컴퓨터 이름과 함께 보인다.
- 기기 종류에 **Android TV**, **Google TV**, **Android 휴대폰**이 추가됐다.
- 설정 › 연결된 기기에 MAC과 **이전** 표시가 보인다.

## Android 인증서 안내

- Android TV·Google TV는 기기에 CA를 설치하는 대신 디버그 빌드의 `network_security_config`에 CA를 넣도록 안내한다.
- CA 지문 비교, adb 프록시 설정·해제 방법을 함께 담았다. 끝나면 프록시를 꼭 해제한다.

## 알려진 제한

- 1.3.0 이하 앱이 devices.json을 다시 저장하면 **이전** 기록의 이름이 사라질 수 있다.
