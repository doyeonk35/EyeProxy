## 2. 알아 둘 결정·달라진 점

스펙에서 Proxyman 자료로 확인하지 못해 내가 정한 것(스펙의 **(내 판단)**):
- 패턴 `?`(한 글자) 지원: Proxyman 목록을 가져왔을 때 같은 뜻이 되게 SSL 매칭에도 넣었다.
- 그룹은 사이드바 선택의 한 종류(`SidebarItem.group`)이고 탭은 출처 하나를 본다. 다른 항목을 누르면 출처가 바뀐다.
- New Domain or App… ⇧⌘K의 동작 전체(이름 비우면 "외 N", 줄·쉼표 입력, 고르기 목록, 가져오기…, Favorites에 저장 기본 켬, Open이 새 탭, 사이드바 선택으로 미리 채우기).
- General ▸ Restore Tabs at Launch(기본 켬).
- 복원은 칩·숨김 포함·정렬·선택·펼친 도메인을 저장하지 않고 필터 규칙만 저장한다.
- 복원 순서: 첫 창은 언제나 라이브 탭이고, 저장본에 라이브 탭이 없으면 빈 탭이 아니라 마지막 저장 필터 규칙으로 시작한다(스펙 "빈 라이브 탭"을 컨트롤러가 이렇게 정했다). 사라진 그룹을 보던 탭은 저장해 둔 그룹 정의로 복원한다.
- 사라진 파일 탭은 알림 없이 건너뛰고 Open Recent도 건드리지 않는다.
- MAC은 같은 주소 60초에 한 번만 읽고, 기록은 지우지 않으며 주소마다 가장 최근 기록이 그 주소를 대표한다("이전" 기록은 이름과 MAC을 유지).
- 이 Mac의 LAN IP 이름은 Bonjour가 아니라 시스템 컴퓨터 이름을 바로 읽는다(권한 창이 뜨지 않게).
- Cast `md`로 종류 판단: "Google TV" 포함이나 "Chromecast"로 시작하면 Google TV, Google Home·Nest 계열은 비움, 그 밖은 Android TV.
- 호스트 목록 파일 형식(UTF-8 평문, 한 줄 하나, `#` 주석)과 가져오기는 Append만(덮어쓰기 없음).
- 그룹 Export는 앱 항목을 파일에 넣지 않는다(앱 키는 Mac마다 다를 수 있다).

구현 중 달라진 점:
- **MAC 조회는 로컬 네트워크 권한이 필요할 수 있다.** 스펙은 "권한이 필요 없다"고 했지만, Task 5에서 이 macOS(27.2)의 `sysctl`(`NET_RT_FLAGS`, `RTF_LLINFO`)이 자체 컴파일한 바이너리에는 항목을 하나도 주지 않았다(같은 시각 `arp -an`은 28개). 코드는 비면 조용히 IP 기준으로 돌아가고 알림도 없다. 권한이 있을 때의 동작은 실제 앱에서 확인하지 못했고 `sockaddr_dl` 배치도 실제 ARP 항목으로 확인하지 못했다(arp.c·SDK 구조체와 합성 테스트로 맞춤). 최악에는 macOS 26+에서 MAC 기능이 안 될 수 있다.
- 그룹 우클릭 Enable SSL Proxying에도 `*` 확인 알림이 붙었다(가져오기와 같은 문구, 추가/취소). 기기·앱 "for All Domains"는 실제 호스트만 더하므로 알림이 없다.
- SSL 목록 합치기가 대소문자를 무시한다(대소문자만 다른 호스트는 더하지 않음).
- 복원한 앞 탭을 앞으로 내는 시점이 `.rest(i)`와 `.main`에서 다르다(Task 9 보고서의 타이밍 차이). 어느 탭이 키가 되는지 점검표 2번에서 본다.
- 설정 ▸ SSL의 가져오기 결과·오류 알림은 메인 창이 보여 준다(기존 패턴이라 설정 창 뒤에 뜰 수 있다).
- `Localizable.xcstrings`는 이번에도 갱신하지 않았다(새 한국어 문구는 원문 그대로 보인다). Certificate 메뉴 항목은 여전히 실기기·에뮬레이터 탭만 연다(TV 전용 메뉴 항목 없음).
- 세션 파일 형식 변경 없음(`index.json` version 1). `devices.json`의 `kind`에는 옛 값만 쓰고 새 종류는 `extendedKind`에 쓴다(옛 릴리스 앱이 손상으로 보지 않게).

## 3. 수동 점검표(사용자)

**호스트 그룹**
- [ ] ⇧⌘K → 도메인 두 개와 앱 하나로 그룹을 만든다. 새 탭 제목이 그룹 이름이고 맞는 요청만 보인다.
- [ ] 시트가 앞 탭 창에 뜨고 사이드바 선택(도메인·앱·그룹)에 따라 미리 채워진다(그 밖이면 빈 초안).
- [ ] 도메인 칸이 줄·쉼표를 받고 URL을 붙이면 호스트만 남는다. 형식이 틀린 항목은 빨간 "형식이 맞지 않는 항목 N개는 버립니다"가 보인다.
- [ ] 검색칸이 두 고르기 목록을 거르고, 체크·해제가 도메인 줄·앱을 더하고 뺀다("기타"는 목록에 없다).
- [ ] 시트의 가져오기…가 새 패턴만 더한다. 파일 오류 알림이 시트가 떠 있는 동안에도 보인다.
- [ ] Favorites에 저장을 켜면 Favorites ▸ Groups에 생기고 새 탭이 그 그룹을 고른 상태로 열린다. 라이브 탭은 라이브 탭, 파일 탭은 같은 파일 탭으로 열린다. 끄면 저장되지 않는다.
- [ ] Favorites ▸ Groups 배지 수가 맞는다. 그룹이 없으면 "⇧⌘K로 그룹 만들기"가 보인다.
- [ ] 그룹 우클릭: Open as New Tab · Edit… · Enable SSL Proxying · Export… · Delete가 동작한다. 앱만 든 그룹은 Enable·Export가 꺼진다.
- [ ] Edit하면 열린 탭에 반영되고(다시 거르고, 줄 강조가 유지된다), Delete해도 열린 탭은 유지된다.
- [ ] 이름·검색칸에서 ⏎는 Open·Save이고, 도메인 입력칸 안에서 ⏎는 줄바꿈이다.
- [ ] `*`가 든 그룹에서 Enable SSL Proxying: 확인 알림이 뜨고 취소는 목록을 안 바꾸며 추가는 합치고 SSL을 켠다.

**SSL 목록**
- [ ] 레포 밖의 팀 목록 파일을 설정 ▸ SSL Proxying ▸ 가져오기…로 가져온다. 확인 알림의 개수·버린 줄 수와 `*` 경고가 맞고, 목록이 늘고 SSL이 켜지며 파일 이름의 그룹이 생기고 결과 알림이 뜬다.
- [ ] 빈 파일, 1 MB 초과, 바이너리, 깨진 Proxyman JSON은 각각 맞는 오류가 뜬다. Proxyman SSL JSON과 `.config`도 고를 수 있고 가져와진다.
- [ ] 내보내기…가 `ssl-proxying-list.txt`(머리 주석 포함)를 저장한다(자동 열기를 켜면 Finder가 열린다). 목록이 비면 버튼이 꺼진다. 내보낸 파일을 다시 가져오면 "새로 0개"다.
- [ ] 기존 Enable SSL Proxying 진입점(호스트 행, 목록, HTTPS Response 안내)이 예전처럼 동작한다.

**기기·앱 한 번에 켜기**
- [ ] 기기 우클릭 Enable SSL Proxying for All Domains 뒤 그 기기의 HTTPS가 복호화된다.
- [ ] 앱 우클릭 같은 메뉴가 그 앱이 쓴 호스트를 모두 더한다(사이드바 Filter를 입력한 상태에서도).

**탭 복원**
- [ ] 라이브 탭 3개(전체·기기·그룹)와 파일 탭 1개를 열고 ⌘Q → 다시 실행하면 같은 순서이고, 앞 탭과 필터 규칙이 복원된다. 같은 파일을 연 두 번째 탭과 호스트 탭도 확인한다.
- [ ] 앞 탭이 가운데 복원 탭이던 경우와 첫 라이브 탭이던 경우에 어느 탭이 앞에 오는지 본다(알려진 타이밍 차이).
- [ ] 저장한 그룹을 지운 뒤 재실행해도 그 그룹 탭이 저장해 둔 정의로 복원된다. 그룹을 Edit한 뒤에는 복원한 탭이 새 패턴을 쓴다.
- [ ] 파일을 옮기거나 지운 뒤 실행하면 그 탭만 빠지고 알림이 없고 Open Recent도 그대로다.
- [ ] `.eyeproxy`·`.har` 더블클릭으로 실행하면 복원한 탭이 먼저, 연 파일이 마지막에 앞 탭으로 열리고 Breakpoints 창이 남지 않는다.
- [ ] Restore Tabs at Launch를 끄면 라이브 탭 하나로 시작하고 마지막 라이브 탭 규칙이 그대로다.
- [ ] 창을 다 닫고 종료한 뒤에는 라이브 탭 하나로 시작한다(마지막 저장 필터 규칙으로).
- [ ] 종료 확인 알림에서 취소한 뒤 탭을 바꾸고 다시 종료하면 나중 상태가 복원되고, 취소한 사이에는 저장본이 바뀌지 않는다.
- [ ] 다른 창으로 옮긴 탭(Move Tab to New Window)이 있으면 앞 창 탭이 먼저, 나머지가 뒤에 한 창으로 모인다.

**MAC**
- [ ] **이 macOS에서는 로컬 네트워크 권한 없이 sysctl ARP 표가 비어 올 수 있다.** 권한을 허용한 뒤 설정 ▸ 연결된 기기에 MAC이 보이는지 확인한다(안 보이면 권한 상태와 macOS 버전을 기록한다).
- [ ] TV에 이름을 붙인 뒤 공유기에서 IP를 바꾸거나 DHCP 임대를 갱신한다. 새 IP에서도 이름이 보이고 연결된 기기에 MAC이 보인다.
- [ ] 다른 기기가 옛 IP를 받으면 옛 기록에 회색 "이전"(마우스를 올리면 설명)이 붙고, 그 기기가 돌아오면 이름이 되살아난다.
- [ ] ARP가 비어도 알림이 뜨지 않는다.

**이 Mac**
- [ ] 다른 기기 설정에 Mac LAN IP를 프록시로 넣고 Mac 브라우저도 LAN IP 프록시로 보내 본다. Remote devices에 컴퓨터 이름과 노트북 아이콘이 보이고 연결된 기기에 종류 "이 Mac"이 보인다.

**Android 종류**
- [ ] Google TV가 처음 트래픽을 보낼 때 종류가 Google TV로 채워진다(로컬 네트워크 허용 상태). Google Home·Nest 스피커는 종류가 비어 있다.
- [ ] 연결된 기기의 종류 고르기에 Android TV·Google TV·Android 폰이 있고 직접 고른 값이 이긴다.

**호환**
- [ ] Debug 앱에서 Google TV 종류를 저장한 뒤 릴리스 Prog를 실행한다. 기기 목록이 그대로이고(종류만 알 수 없음) `devices.corrupt-*.json`이 생기지 않는다.

**Android 안내**(Certificate ▸ Install Certificate on Android)
- [ ] 탭이 "실기기 / 에뮬레이터 / Android TV·Google TV"이고, 실기기 탭에 Android 11+ 안내 한 줄이, 에뮬레이터 탭에 "아래 디버그 빌드 방법도 됩니다."와 `adb로 프록시 설정 + CA 복사`가 있다.
- [ ] TV 탭에 단계 다섯 개, TV IP 입력칸 예시 `192.0.2.10`, adb가 있으면 connect·프록시 설정·프록시 해제 버튼과 해제 바로 아래 주황 경고가 있고 CA push 버튼은 없다.
- [ ] adb가 없는 환경(PATH에서 뺀 경우)에서는 connect+설정 두 줄과 해제 한 줄 복사용 명령이 각각 복사 버튼과 함께 보이고 주황 경고가 뒤따른다.
- [ ] "디버그 빌드에 CA 넣기"(모든 탭): 지문이 현재 CA SHA-256과 같고, 복사 버튼이 동작하며, "CA를 proxy_ca.crt로 저장…"이 `proxy_ca.crt` 기본 이름의 PEM을 저장하고, cp 명령에 실제 CA 경로가 들어 있고, XML 스니펫이 읽기 좋게 줄바꿈된다.
- [ ] 디버그 빌드에 `proxy_ca.crt`를 넣고 `openssl x509 -in … -noout -fingerprint -sha256` 지문이 창의 SHA-256과 같다.
- [ ] `adb로 프록시 설정`(TV 탭)이 프록시만 설정한다(`settings get global http_proxy`가 Mac IP:포트). TV 앱 요청이 Prog에 보인다.
- [ ] 프록시 해제 버튼 뒤 `settings get global http_proxy`가 `:0`이다.

## 5. 머지 메모

- 새 패키지 없음. Info.plist 변경 없음.
- 새 UserDefaults 키 셋: `eyeproxy.hostGroups`, `eyeproxy.openTabs`, `eyeproxy.restoreTabsAtLaunch`(없으면 기본값).
- `devices.json`에 새 키 `mac`, `extendedKind`. `kind`에는 옛 값만 쓰므로 옛 릴리스 앱도 파일을 읽는다(다시 저장하면 새 키는 빠진다).
- 세션 파일 형식(`index.json` version 1) 변경 없음.
- 머지 전 점검표 중 MAC(로컬 네트워크 권한)·탭 복원·Android 안내는 손으로 한 번 보는 것을 권한다.
